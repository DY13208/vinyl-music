# 模型接入与提示词安全

## 适用范围

新增模型网关、提示词模板、结构化输出、流式响应、工具调用、重试和模型配置时使用。具体模型供应商可以更换，领域代码不得依赖某一家 SDK 的响应类型。

## 调用边界

- 浏览器代码不得持有供应商 API key、服务账号令牌或可长期复用的签名。所有构建时公开变量都不能存放秘密。
- 需要秘密的调用必须由后端模型网关完成。网关使用最小权限、显式模型 allowlist、超时、取消、重试上限和成本上限；客户端不得任意传入模型名、系统提示词、工具权限或采样上限。
- 请求只发送完成任务所需的最小字段。专辑收藏、用户备注和导入文件默认视为用户数据，未经明确授权不上传第三方模型。
- 模型不可直接操作数据库、`localStorage`、播放器或导航；模型结果必须经过应用代码校验后才能触发副作用。
- 模型工具只暴露按用例定义的最小动作。每次工具调用重新检查用户授权、资源所有权、参数 schema 和幂等键；模型不能自授予权限或绕过人工确认。
- 对话、提示词、上下文和输出按数据保留策略处理；默认不把敏感用户数据用于训练或长期日志，供应商存储选项必须经过配置审查。

## 提示词与输出

- 提示词使用版本化模板，记录模型、版本、温度/上限等影响结果的配置；不要把用户输入拼成新的系统指令。
- 外部文本（歌词、专辑简介、导入文件）视为不可信内容，不能因为其中出现“忽略规则”等文字而改变系统约束或工具权限。
- 优先要求 JSON Schema 结构化输出，并在运行时校验必填字段、枚举、字符串长度、数组数量、URL 协议和数值范围；解析失败走可见错误状态，不静默使用半截结果。
- 对模型超时、限流、空结果、内容安全拒绝和供应商错误提供可恢复状态；日志记录 request id、耗时和错误类别，不记录密钥、完整提示词中的敏感数据或完整用户内容。
- 重试只用于可判断为临时的错误，并设置指数退避与次数上限；写入操作必须带幂等键或结果去重，避免重复导入、重复收藏和重复计费。
- 流式响应在传输层使用明确的事件协议、序号和终止事件；客户端断线后不能把未完成内容当成成功结果，服务端落库必须等待完整校验。
- 记录模型、版本、提示词版本、输入摘要、耗时、token/费用估计和结果状态等可观测字段；原始用户文本、密钥和完整歌词不进入普通日志。

## 验证要求

- 新增模型接入至少验证：有效响应、schema 失败、超时/限流、空结果、恶意外部文本、无密钥配置和服务不可用。
- 未配置真实模型凭据时，只能验证 mock/fixture 路径；真实供应商、限额、内容安全和数据保留行为必须单独标注为未验证。
