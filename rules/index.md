# Vinyl Music 项目规则入口

本目录只承载 TypeScript 后端、React 19、PostgreSQL 18 和 AI 功能相关的项目级约束。

| 场景 | 进入目录 | 直接看 |
| --- | --- | --- |
| 判断模块职责、依赖方向和前后端契约边界 | `architecture/` | [`architecture/index.md`](./architecture/index.md) |
| 编写 TypeScript API、领域服务、Repository 或后台任务 | `backend/` | [`backend/index.md`](./backend/index.md) |
| 编写 React 19 页面、组件、API 状态或音频交互 | `frontend/` | [`frontend/index.md`](./frontend/index.md) |
| 设计 PG18 数据模型、查询、事务、锁或迁移 | `data/` | [`data/index.md`](./data/index.md) |
| 接入模型或管理 AI 生成内容 | `ai/` | [`ai/index.md`](./ai/index.md) |
| 处理鉴权、会话、密钥、错误脱敏或运行时保护 | `security/` | [`security/index.md`](./security/index.md) |
| 为具体变更选择项目验证项 | `project/` | [`project/verification.md`](./project/verification.md) |
