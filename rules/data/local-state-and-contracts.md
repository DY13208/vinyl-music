# 客户端本地状态与存储

- PostgreSQL 18 是登录用户业务数据的权威来源；React state、server-state cache、`localStorage` 和 IndexedDB 都是临时投影或草稿。
- `localStorage` 只保存主题、布局、最近视图等可丢失偏好；IndexedDB 只在明确的离线需求下保存带版本、过期和同步状态的数据。
- Token、数据库或模型密钥、完整敏感内容、权限结论和不可撤销业务事实不得写入脚本可读的浏览器持久化。
- 读取本地数据要处理 schema 版本、JSON 解析失败、旧字段、容量限制和单条损坏；失败时隔离坏记录并回退到安全状态。
- 登录主体切换或退出时，清理用户范围内的缓存、离线草稿和持久化数据；缓存键必须包含用户范围，避免跨账号显示。
- 离线写操作必须记录本地任务 ID、服务端幂等键、创建时间和同步状态；恢复联网后按明确冲突策略同步，不静默覆盖服务端较新数据。
- 异步响应带请求身份或版本条件，过期结果不能覆盖用户刚完成的编辑；失败时保留草稿并显示可重试状态。
