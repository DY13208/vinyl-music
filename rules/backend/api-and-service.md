# API、DTO 与服务适配

## HTTP 契约

- API 使用版本化路径或等价的显式版本策略；请求、响应和错误都由具名 DTO 与运行时 schema 定义。
- 校验边界覆盖 body、path、query、header 和外部响应。TypeScript 静态类型不能替代运行时校验。
- DTO 只暴露调用方需要的字段；禁止直接序列化数据库行、ORM Entity、模型供应商响应或内部 `metadata`。
- 时间统一使用 UTC 的 ISO 8601 字符串；持续时间使用明确单位；价格或金额使用整数最小单位或精确定点类型，不使用浮点数。
- 可选字段、`null`、空字符串、空数组和缺省值必须有不同且明确的语义。服务端不得依赖前端猜测默认值。

## 错误、分页和缓存

- 错误响应使用稳定的机器码、可理解消息和 request id；SQL、表名、堆栈、密钥和第三方原始错误只留在脱敏后的内部日志。
- 资源不存在与无权访问的响应按安全模型统一，避免通过差异响应枚举其他用户的数据。
- 大列表采用稳定排序的游标分页；游标包含排序键与唯一键并校验签名/结构。仅在小型、固定数据集使用深度可控的 offset 分页。
- GET/HEAD 保持无副作用；缓存头、ETag 和条件请求需与权限范围一致，私有数据不得进入共享缓存。

## 写操作与幂等

- 创建、导入、AI 生成任务和重试型写入支持幂等键；后端在数据库中以调用方范围和键建立唯一约束，返回第一次请求的确定结果。
- 更新接口明确采用整体替换或局部修改语义；并发编辑使用版本号、更新时间条件或 ETag，不能静默覆盖较新数据。
- 批量接口设置条数和 payload 上限，明确全成功、逐项结果或事务回滚语义；禁止一部分静默失败。
- 删除操作明确资源、关联数据和恢复策略。异步删除返回可查询任务状态，不能先显示成功再隐藏失败。

## 外部服务适配

- 音乐目录、歌词、封面、对象存储和模型供应商均经后端 adapter 访问；对目标主机、协议、响应大小和重定向设 allowlist，防止 SSRF 与资源耗尽。
- 客户端设置连接和请求超时、响应大小上限、有限重试和退避；只对安全且可重试的操作重试。
- 供应商标识、状态和原始错误映射为项目领域类型；供应商 SDK 类型不得穿透到 API DTO 或领域层。
