# 后端公用组件

这里存放 TypeScript 后端跨业务复用且与具体领域无关的组件，例如请求上下文解析、分页/游标、错误映射、schema 校验适配、幂等执行器、超时与重试策略和可观测性中间件。

新增后端代码前先检查 `backend/src/` 及对应 feature 的现有实现：

1. 已有等价能力时通过稳定接口复用，不复制平行版本。
2. 只有一个用例使用且没有稳定变化边界时，保留在该用例模块内。
3. 至少两个独立模块共享同一职责和不变量时，抽取到本目录，并保持无业务归属、无 HTTP/ORM 供应商泄漏的边界。
4. 公用组件不得偷偷创建数据库连接、事务、全局可变状态或模型客户端；依赖通过参数或接口注入。

领域规则、领域实体和 feature 专属 Repository 不放入本目录；它们应留在 `domain/`、`application/` 或对应 feature 中。
