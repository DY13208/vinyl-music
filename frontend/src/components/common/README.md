# 前端公用组件

这里存放跨业务页面、跨 feature 复用且职责稳定的 React 19 组件，例如按钮、弹窗、表单控件、状态展示、分页和无障碍辅助组件。

新增组件前先检查 `frontend/src/components/` 与各 feature 的现有实现：

1. 已有等价组件时直接复用，不在页面中复制一份。
2. 只有一个页面使用且没有稳定复用边界时，保留在页面或 feature 内，不强行入库。
3. 两个及以上业务场景共享相同交互、视觉状态或可访问性行为时，抽取到本目录，并通过 props/明确类型参数化。
4. 组件必须自包含 loading、empty、error、disabled、focus 等适用状态，且不直接读取数据库、模型 SDK 或业务 API。

组件进入本目录后，后续页面优先使用该实现；破坏性 API 变化需要同步调用方和验证记录。
